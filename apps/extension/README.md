# Dollarino Companion Browser Extension (v9.7)

اکستنشن رسمی دلارینو با طراحی **Apple Liquid Glass** هم‌شکل سایت برای مرورگرهای Chrome، Edge، Brave و Opera:
- کارت کوبالتی Hero همراه با موجودی، سود باز، نمودار Sparkline و وضعیت زنده ربات
- نوار تب کشویی نرم (فرماندهی، بازارها با مینی‌چارت، رادار DEX و سوآپ Trust Wallet، اتصال و رفرال)
- آیکون‌های اختصاصی ارزها، گیج ایمنی توکن‌ها و پشتیبانی کامل از هر دو تم روز (`Paper`) و شب (`Cosmic`)
- کنترل ۱-کلیکی ربات، اسکن فوری AI و توقف اضطراری (Kill Switch)

## راهنمای نصب سریع:
1. این فایل ZIP را از حالت فشرده خارج کنید (Extract).
2. در مرورگر Chrome آدرس `chrome://extensions` را باز کرده و **Developer mode** (بالا سمت راست) را روشن کنید.
3. دکمه **Load unpacked** را بزنید و پوشه خارج‌شده را انتخاب کنید.
4. کلید اکستنشن خود (`dlr_ext_...`) را از ربات تلگرام `@Dollarino_bot` یا بخش ابزارهای سایت کپی و در تب «اتصال» وارد کنید.
